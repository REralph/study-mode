Blocking

Study Mode is always on. Blocking can't be switched off from here.

Dozens of distracting sites included with the extension: short-video and social media apps, streaming and browser games. Each entry also blocks its subdomains. Works offline.

Catches mirror and look-alike sites that aren't on any list.

Stops "just one quick search" on Google, Bing, DuckDuckGo, Yahoo, YouTube, Brave, Ecosia, Startpage, Yandex, Reddit and X.

Blocked sites

One per line. example.com blocks the site and all its subdomains; youtube.com/shorts blocks just that section.

Exceptions

Sites that should stay reachable. One per line, written the same way as Blocked sites.

When an exception and a block entry both match

  1. The more specific entry wins. An exception for example.com unblocks it and its subdomains, but a block entry for games.example.com, yours or the built-in list's, still blocks that subdomain. A section such as example.com/videos is more specific than the whole site.
  2. Same site on an exception and the built-in list: the exception wins. Use this to unblock a site you need for a course.
  3. Same site on an exception and your Blocked sites: blocking wins.
  4. An exception also turns off keyword matching in that site's address. Searches are still checked.

Keywords

Matched anywhere in site addresses and search queries, so short or common words cause false blocks. One per line, at least 3 characters.

Password lock

A password stops impulsive changes, for example when a friend or a parent keeps it. Anyone with access to Firefox's Add-ons page can still remove the extension; the README explains how to lock it in place with a Firefox policy.
